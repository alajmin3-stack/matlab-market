# مطلب

واجهة سوق إلكتروني عربية متجاوبة، مصممة لعرض الإعلانات وتصفح الأقسام والبحث وإدارة الرسائل والمفضلة.

## الموقع

[افتح موقع مطلب](https://alajmin3-stack.github.io/matlab-market/)

## الملفات المهمة

- index.html: صفحة الموقع.
- app.js: الصفحات والتنقل والبيانات التجريبية.
- styles.css و modern.css: التصميم المتجاوب.
- matlab-logo.jpg: الشعار.

لتحديث الموقع، عدّل الملفات ثم ارفع النسخة الجديدة إلى الفرع main؛ سيُعاد النشر تلقائيًا.
